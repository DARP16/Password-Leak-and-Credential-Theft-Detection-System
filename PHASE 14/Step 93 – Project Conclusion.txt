This project presented a machine learning-based Password Leak and Credential Theft Detection System capable of identifying suspicious login attempts using behavioural analysis and engineered security features. A unified dataset was prepared by integrating multiple behavioural indicators, followed by feature engineering and the computation of the proposed Behaviour Drift Index (BDI), Adaptive Behavioural Fingerprint Entropy (ABFE), and Dynamic Credential Risk Score (DCRS). A Random Forest classifier was trained and evaluated, demonstrating excellent performance in distinguishing between legitimate and malicious login attempts. To improve model transparency, SHAP explainability techniques were applied, and the final solution was deployed through a Streamlit dashboard, providing an interactive interface for real-time risk prediction. The overall results demonstrate that the proposed framework is effective, interpretable, and suitable for credential theft detection.
